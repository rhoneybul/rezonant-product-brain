# As a visitor browsing events, I want to trigger plan generation from an event, so that I can explore what training for it would look like

## User Story

As a visitor browsing events, I want to trigger plan generation from an event, so that I can explore what training for it would look like.

## Acceptance Criteria

- [ ] Each event card on `events.html` has an active "Build a training plan" button that opens the plan configuration flow (currently the button exists but behaviour is undefined — activate it)
- [ ] The "Get your guide with Etapa" CTA on individual `event.html` pages opens the same plan configuration flow (currently marked "coming soon" — remove the disabled state and wire it up)
- [ ] Clicking either CTA opens a modal overlay without navigating away from the current page
- [ ] The modal displays the event name, date, and discipline pre-filled at the top so the user knows which event the plan is being built around
- [ ] The modal is mobile-responsive and works correctly on viewport widths from 375px upward

## Definition of Done

- [ ] Feature is implemented and tested
- [ ] UI/UX meets design requirements
- [ ] Both entry points (event card and event detail page) launch the same configuration modal

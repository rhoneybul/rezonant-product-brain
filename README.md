# Etapa Product Brain (placeholder)

This is the **default branch** of the Etapa Product Brain repo and
holds only this placeholder.

All brain content lives on the **`brain` branch**, which is the primary working
branch. The brain is written constantly (scheduled ingestion, manual inputs, and
a wiki update on every processing run), so it is kept off the default branch to
avoid default-branch protection rules blocking those writes.

Switch to the [`brain` branch](../../tree/brain) to see the synthesized wiki.

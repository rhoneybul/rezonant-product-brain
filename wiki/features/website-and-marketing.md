# Website and Marketing

## Account creation on the website (ETA-622 — In Progress)

A login / create-account flow on the website that lets visitors sign in or create an account and view their plans at a high level. Deeper detail (session structure, coaching) remains app-only. **In Progress as of July 2026.**

## Buy plan on website (ETA-618 — Backlog)

Allow plan purchase directly on the website. No implementation detail recorded.

## Events page (ETA-584, ETA-550, ETA-627)

See [events-and-trips article](events-and-trips.md) for full detail. Key items:
- Events page filter bugs and card layout improvements (ETA-584)
- Drive traffic via SEO/AEO/ads (ETA-550)
- Event-triggered plan generation CTA (ETA-627 — Backlog)

## Sample session marketing demo (session 3606f46d)

**Concept explored:** A read-only "sample session" page visible to visitors without sign-up, showing mocked stats (route map, elevation, power data, lap breakdowns) to demonstrate Etapa's coaching and analytics capabilities.

**Status:** Prototype discussion only; no final technical decision. A PRD or technical spec was offered as the next step following prototype validation. Not yet a Linear ticket.

**Strategic value:** Lowers the evaluation barrier for prospective users who can see what a Etapa session looks like before committing to an account.

## Podcast on website (ETA-611 — In Review)

Embed the Etapa podcast (Spotify) on the website and allow listener questions. Embed code exists in ticket.

## Social sharing (ETA-610 — In Review)

## Buy your guide (ETA-547 — Backlog)

Allow visitors to purchase a single event guide for £20 directly from the event list on the website — without needing a full app subscription. This is a lower-commitment entry point than a subscription, useful for one-off event participants.

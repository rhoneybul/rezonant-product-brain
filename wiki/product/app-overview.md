# Etapa — Product Overview

Etapa is an AI-coached endurance and cycling training app targeting beginner and returning riders. It generates personalised training plans, guides riders through individual sessions, connects to Strava and WHOOP for activity data, and supports multi-day bikepacking trips and events.

## Core product pillars

| Pillar | Summary |
|--------|---------|
| **AI coaching** | Personalised training plans generated by AI; in-app coach chat (Sophie and others) answers questions and adjusts the plan |
| **Training sessions** | Structured ride, gym/strength, and swim sessions with logging, timers, and set tracking |
| **Plan management** | Weekly calendar view, scheduled sessions, plan overview with progress graph |
| **Strava integration** | Sync completed activities, show Strava sessions on week view, surface Strava saved routes in route planning |
| **WHOOP integration** | Push completed gym sessions to WHOOP; morning recovery check-in (roadmap) |
| **Route planning** | AI-generated and community route discovery for single-day rides; GPX import/export; Trailforks MTB trails (pending credentials) |
| **Events and trips** | Browse cycling events and multi-day bikepacking trips; event-triggered plan generation |
| **Website** | Marketing site with events page, podcast, and (in progress) account creation + plan purchase |

## Technology notes

- React Native mobile app (iOS first; Strava not yet available on Android — ETA-601 open)
- Supabase backend; Railway hosting
- PostHog for analytics; migration of feature flags from admin dashboard to PostHog in backlog (ETA-607)
- RevenueCat for subscriptions; free-trial then paid model
- Remote config via `GET /api/app-config`; per-user overrides via admin dashboard

## Current phase

App is in TestFlight / closed beta. Pre-launch legal review in progress (ETA-588). Public launch gating on solicitor sign-off, ICO registration complete, health-data consent, and App Store/Play Store asset preparation.
